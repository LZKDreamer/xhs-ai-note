# 通用钩子库（图文正文 + 视频口播共用）

> **解决什么问题**：`口播稿规范.md` §五有 4 种开场结构 + 3 种语气形态，但**图文正文开头只有一句"第 2 行起是钩子，不铺垫"**——没有结构库可命中。本文件把口播的钩子结构泛化成图文正文也能直接套的共用库，并由 `check-copy.mjs`（W5）机械校验"正文前 3 行必须命中其一"。
> **来源**：4 结构 + 3 形态拆自真人爆款视频，已在视频侧验证可用；图文正文复用同一套。

---

## 一、为什么"开头有钩子"是硬指标

- 小红书图文：正文首屏（前 3 行）决定读者要不要往下滑。**没有钩子的开头 = 直接被划走**。
- 视频：前 3 秒 = 生死。`口播稿规范.md` §五的硬规则同样适用图文正文。
- 钩子和封面主标题**必须是两条不同的话**，但指向同一命题（封面求点击，开头求停留）。

---

## 二、4 种可直接套的开场结构

| # | 结构 | 句式骨架 | 适用 |
|---|---|---|---|
| 1 | **条件式后果** | 「用 X 的时候，如果不 Y，就会 Z（把恶果具象化）」 | 原文讲"常见误用 / 错误用法"时 |
| 2 | **收益带数字** | 「这一条能帮你降低 N% / 省 N 分钟 的 Y」 | 原文有可量化收益（数字必须可核查） |
| 3 | **门槛拆除** | 「就 N 步 / N 分钟，就能 X」 | 原文是流程/教程，钩子末尾拆掉"这很难" |
| 4 | **提问代入** | 「如果现在让你马上做 X，你脑子里的第一步是什么？」 | 普遍成立的场景；问完立刻接诊断 |

**组合用法**（推荐，视频口播已用）：4（提问）→ 停顿 → 1（后果）→ 2（收益）→ 3（拆门槛）→ 节奏标记。
图文正文不必这么长，**前 3 行命中任一结构即可**。

---

## 三、3 种语气形态（与上面 4 结构正交，可叠加）

| 形态 | 结构 | 例 |
|---|---|---|
| 代价型 | 你为这个错误付了多少时间 / 钱 | 同一件事，你跟 AI 说过多少遍？ |
| 反常识型 | 你以为 A，其实 B | AI 记不住你，问题不在提示词 |
| 场景代入型 | 复述他**普遍会做**的那件事 | 换个对话，就得从头再教一遍 |

---

## 四、图文正文怎么用（与视频口播的差异）

| | 视频口播 | 图文正文 |
|---|---|---|
| 长度 | 钩子段 0–5s / ≤29 字 | 正文前 3 行内命中一种结构 |
| 节奏标记 | 钩子末尾必须 2–4 字（「直接开始」） | 不强制（文字天然有停顿），但前 3 行末尾最好给一个转折词 |
| 第一句 | ≤15 字、完整单句 | ≤25 字、完整句，**禁从句套从句** |
| 禁铺垫 | 同 | 同——不先讲背景 / 定义 / 自我介绍 |

**示例（wb-ch05 正文开头，提问代入型）**：
> 先做个小测试：回想一下，你最近跟 AI 说过多少遍「不要写得太AI」「长短句结合」「要有自己的判断」「不确定的别编」？

**反例（说明书式开头，会被 W5 拦）**：
> Skill 是一组可复用的说明、脚本、参考资料和资源。它的工作原理是……

没有提问 / 数字 / 否定 / 人称代词 → 不是钩子，是定义。读者没理由往下看。

---

## 五、脚本校验（W5）

`check-copy.mjs` 的 W5：**正文前 3 行必须命中钩子标记之一**——人称代词（你/我）/ 数字 / 疑问 / 否定（不/别/没）/ 反常识词（其实/以为）。
命中即过；不命中 = 警告（W 级，不阻断出图，但要在交付前人工确认开头真的有钩子）。

> 为什么是 W 不是 C：钩子好坏最终靠人判断，机械只能查"有没有钩子标记"。把 W1（封面主标题标签启发式）和 W5（正文开头）对称起来。

---

## 六、钩子链设计（封面 → 痛点页 → 正文 → 兑现内页）

四个钩子位应是**同一痛点的四个层次**，不是四句同义重复：

| 钩子位 | 任务 | wb-ch05 实例 |
|---|---|---|
| 封面主标题 | 给冲突结论（求点击） | 100 遍提示词，AI 还是记不住 |
| 痛点页标题 | 给行为细节（求共鸣） | 你是不是每次都要跟 AI 说同一句话 + 4 句真实台词 |
| 正文前 3 行 | 给代价提问 / 场景（求停留） | 先做个小测试：你最近跟 AI 说过多少遍…… |
| 兑现内页 | 给答案 / 能带走的东西（求收藏） | Skill 是写给 AI 的长期工作说明书 + 五件事模板 |

**规则**：封面钩子、痛点页标题、内页标题之间**不得同义重复**（硬约束 20 + C12）；但应**递进不重复**——每个钩子位推进一层，不是换词重说同一句。
