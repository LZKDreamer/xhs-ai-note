# 封面对标档案

> **规则**：见 `references/选题库规范.md` §三（每周看 3 个对标账号爆款）。本档案沉淀对标爆款的**封面要素**——
> 现在选题库只记"选题 + 搜索词"，封面语料没有沉淀，导致钩子标签词库和视觉证据类型靠初始假设、不被真实数据迭代。
> **用法**：每周拆 3 张对标爆款封面，按下面字段填一行；复盘时按"钩子标签词 / 视觉证据类型"聚类，回流进 `标题与封面规范.md` §六·一词库。

## 一、拆解字段（每张封面一行）

| 日期 | 对标账号 | 封面主题 | 钩子标签（原话） | 钩子标签类型 | 主标题（原话） | 主标题公式 | 视觉证据类型 | 留白密度（满/中/松） | 可复用点 |
|---|---|---|---|---|---|---|---|---|---|

> **钩子标签类型**：人群词 / 紧迫感 / 数字 / 悬念 / 身份+普遍成立
> **视觉证据类型**：对比卡 / 数字条 / 截图 / 图解 / 实拍 / 纯文字（无证据=不合格，记下当反面）
> **留白密度**：满（内容铺满）/ 中 / 松（>1/4 连续空洞，记下当反面）

## 二、拆解模板（拆一张时问自己）

1. **3 秒看懂讲什么**——它的主标题是结论还是悬念？我们能不能这样写还不违规？
2. **钩子标签写的是什么**——人群词？紧迫感？数字？能不能搬进我们的词库？
3. **视觉证据用了什么**——对比卡 / 数字 / 截图？我们哪条笔记能复用这个类型？
4. **留白密度**——它是满还是松？松的我们记反面。
5. **可复用点**——一句话：哪一句结构 / 哪一个视觉类型，能搬到我们下次的哪类选题。

## 三、回流动作

- 每月底把"钩子标签词"聚类，高频词补进 `标题与封面规范.md` §六·一 词库
- 把"视觉证据类型"分布统计一次——如果对标爆款 70% 用对比卡，我们却 70% 用截图，就是结构偏差
- 数据好的封面（我们自己发的）也抄进本档案，标注"自研"，和对标放一起比
