# 爆款钩子档案

> **规则**：见 `references/数据复盘规范.md`。与 `爆款标题档案.md` 对称——
> 那个沉淀"标题公式 → 数据"，这个沉淀"钩子类型 → 数据"。
> **为什么单独建**：标题管点击，钩子管停留 3 秒（视频）/ 停留首屏（图文）。两者数据归因不同，混在一起看不出钩子强弱。

## 一、记录字段（每条发布笔记一行）

| 发布日期 | 笔记 | 模式 | 钩子位 | 钩子类型 | 钩子原文 | 24h曝光 | 24h完播率/滑到底率 | 24h收藏率 | 备注（钩子做对了什么/差在哪） |
|---|---|---|---|---|---|---|---|---|---|

> **模式**：图文 / 视频
> **钩子位**：封面主标题 / 封面钩子标签 / 痛点页标题 / 正文前 3 行 / 口播场景 1
> **钩子类型**（见 `references/通用钩子库.md`）：
>   - 结构：条件式后果 / 收益带数字 / 门槛拆除 / 提问代入
>   - 形态：代价型 / 反常识型 / 场景代入型
> **24h完播率/滑到底率**：视频取完播率，图文取"滑到底"估算（小红书图文无原生滑到底数据，用收藏率+评论深度代理）

## 二、回流动作

- 每月底按"钩子类型"聚类，算平均收藏率/完播率——哪类钩子数据好，下月多做
- "钩子原文"列单独存档：数据好的钩子原文抄进 `通用钩子库.md` 当语料校准（只校句式，不照抄）
- "钩子做对了什么"列写一句归因，避免下条重复踩同一个坑
