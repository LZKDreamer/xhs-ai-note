# 标题与封面钩子规范

> 来源：`bigpeng-hot-gzh` 的 7 型标题公式 + 8 个选题模板，**已改造为小红书体**。
> 原文是公众号信息流（18–32 字），小红书要更短更狠：**封面主标题 ≤ 16 字，可断 2 行**。

## 一、小红书标题的硬规则

| 项 | 规则 |
|---|---|
| 封面主标题 | ≤ 16 字，断成 2 行，**第 1 行必须有信息量** |
| 正文首行标题 | ≤ 20 字（小红书标题就是正文第一行） |
| 数字 | 必须具体：100 遍、5 件事、3 层。**禁止「多个」「一系列」「干货满满」** |
| 身份词 | 有则用（上班族、零基础、学生党）；没有也要能看懂 |
| 第一人称 | 「我/你」优先于「如何」「关于」 |
| 附赠承诺 | 写了「附模板/附清单」，正文必须有对应物 |
| 禁用 | 震惊、重磅、炸裂、必看；「XX 发布了」「盘点 XX」「关于 XX 的思考」 |

## 二、7 型公式（小红书版）

| # | 公式 | 结构 | 示例 |
|---|---|---|---|
| 1 | 数字清单 | 身份 + N 个 + 对象 | 零基础必存的 5 件事，AI 再也不用重新交代 |
| 2 | 代价+收获 | 我做了 Y（夸张量）+ 结果 Z | 提示词写了 100 遍，AI 还是记不住 |
| 3 | 反转结论 | 以为 A，其实 B | 你的 AI 记不住，不是它笨，是你没存 |
| 4 | 速成教程 | 时长/门槛 + 精通 + 对象 | 零基础也能写：把要求存成 AI 的工作手册 |
| 5 | 社会证明 | 数字 + 对象 + 它干成了什么 | **慎用**：数字必须可核查，编造即违规 |
| 6 | 对比站队 | A 和 B 到底选哪个 | 提示词和 Skill 到底差在哪 |
| 7 | 情绪短句 | 短、口语、带情绪 | 跟 AI 说了一百遍，它还是不懂我 |
| 8 | 概念降维 | 把专业词翻成人话 | 90% 的人卡在这一步：AI 记不住你说过的话 |

**每次至少产出 1 条主选 + 3 条备选，公式不重复。**

## 三、封面设计规则（吸睛的关键）

封面必须同时做到三件事，缺一个就不合格：

1. **3 秒内看懂讲什么** — 主标题就是结论或冲突，不能是悬念句
2. **有视觉证据** — 对比卡 / 数字 / 图解，不能只有字
3. **有理由点开** — 钩子标签（「90% 的人卡在这一步」）+ 附赠承诺（「附模板」）

**封面结构（自上而下）**

```
[钩子标签]      橙底白字胶囊，8–12 字，给紧迫感或人群
[主标题]        得意黑，96–110px，2 行，第 1 行最有信息量
[副标题]        40–46px，一句给解法
[视觉证据]      对比卡 / 图解 / 数字条（占版面 30–40%）
[角标]          2 个胶囊：价值承诺 + 内容形式
```

**反面清单**（本次踩过的坑）：
- ❌ 主标题太文艺、没有数字和冲突
- ❌ 中部大面积空白（不要用 `margin-top:auto` 把内容推散）
- ❌ 只有文字没有视觉证据
- ❌ 添加系列名页眉、页码、来源标注等装饰

## 四、8 个选题模板（映射到章节内容）

| 模板 | 何时用 | 槽位 |
|---|---|---|
| 必装清单 | 有一组可执行物 | 身份 + N 个 + 对象 |
| 亲测复盘 | 做过一次实验/踩坑 | 我用 X 做了 Y + 得到 Z |
| 从 0 到 1 教程 | 读者不会用 | 门槛 + 手把手 + 对象 |
| 热点产品落地 | 新功能发布 72h 内 | 产品名 + 普通人怎么用 |
| 对比抉择 | 两个概念/工具被混用 | A 和 B 到底差在哪 |
| 反常识 | 能挑战读者正在做的事 | 你以为 A，其实 B |
| 身份场景化 | 接到具体岗位就变新选题 | 身份 + 用 X 做 Y |
| 概念降维 | 专业词读者没听过 | 把术语换成一句人话 |

## 五、自检清单

出稿前逐条过：

- [ ] 封面主标题 ≤ 16 字，第 1 行有信息量
- [ ] 标题里有具体数字或明确冲突
- [ ] 封面有视觉证据，不是纯文字
- [ ] 至少 1 条主选 + 3 条备选，公式不重复
- [ ] 主选标题的承诺能在正文兑现
- [ ] 没有禁用词、没有编造数字
- [ ] 正文首行标题 ≤ 20 字
