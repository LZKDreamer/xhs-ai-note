# 标题与封面钩子规范

> **两个来源**
> ① `bigpeng-hot-gzh` 的 7 型标题公式 + 8 个选题模板 + 写法细则 + 失败信号（原文面向公众号信息流，**18–32 字**）
> ② 小红书改造：**封面主标题 ≤ 16 字**、正文首行标题 ≤ 20 字
>
> **公式是槽位，不是语料。** 只借结构，产品名必须换成我们实际在讲的东西。

---

## 零、本项目哪些公式能用（先看这个）

| 公式 | 能否用 | 硬条件 |
|---|---|---|
| 1 数字清单 | ✅ | N 必须是具体整数，正文真有 N 条 |
| 2 我 + 代价 + 收获 | ⚠️ **只在真做过时用** | 需要真实工作量。**绝不编造「我测了 100 个」** |
| 3 反转结论 | ✅ | 反转必须是正文真能解释机制的，不为反转而反转 |
| 4 速成教程 | ✅ | 写了时长 / 字数，正文体量必须配得上 |
| 5 社会证明 | ⚠️ **只在数字可核查时用** | **绝不编造 Star / 下载量 / 实验样本 / 对比分数** |
| 6 对比站队 | ✅ | 对比要有同一任务，抛弃型要真用过被抛弃的那个 |
| 7 情绪短句 | ✅ **最多 1 条** | 后面必须有干货，否则撑不住点击 |
| 8 概念降维 | ✅ 小红书新增 | 把术语翻成人话 |

**只有 1 条主选时，优先 3 反转 / 4 速成 / 6 对比 / 8 概念降维。**

## 一、小红书标题的硬规则

| 项 | 规则 |
|---|---|
| 封面主标题 | ≤ 16 字，断成 2 行，**第 1 行必须有信息量** |
| 正文首行标题 | ≤ 20 字（小红书标题就是正文第一行） |
| **视频口播钩子** | 和封面主标题**必须是两条不同的话**，但指向同一命题 |
| 数字 | 必须具体：100 遍、5 件事、3 层。**禁止「多个」「一系列」「干货满满」** |
| 身份词 | **是点击开关**：上班族、零基础、普通人、创作者、体制内、电商商家、一人公司 |
| 第一人称 | 「我 / 你」优先于「如何」「关于」 |
| 附赠承诺 | 写了「附模板 / 附清单 / 附提示词」，正文必须有对应物 |
| 禁用 | 震惊、重磅、炸裂、必看；「XX 发布了」「盘点 XX」「关于 XX 的思考」 |

**字数怎么算**：汉字、标点、数字、字母**各算 1**；空格不算；英文按实际字母数（`AI` = 2 字，不是 1 字）。

## 二、7 + 1 型公式（小红书版）

> 每条都要写清「**正文必须兑现什么**」。兑现不了就换公式。

### 1. 数字清单

`身份 + 必装/推荐 + N 个 + 对象`

- 上班族必装的 3 个 AI 技能，配一次不用再教
- **兑现**：真有 N 条，每条能装能用，各有一句场景

### 2. 我 + 代价 + 收获

`我用 X 做了 Y（夸张量）+ 得到 Z`

- 我分析了 1000 个 skills，这是最推荐的 30 个
- **兑现**：过程可复述，数字来自真实工作量，结论不是正确废话
- 🚫 **本项目默认不用**：我们没有真实工作量可写，编造即违规

### 3. 反转结论

`以为是 A，其实是 B` / `不是 X，是 Y`

- 你觉得 Codex 不好用，可能是因为它开错了「档位」
- **兑现**：反转要有机制解释，不能只骂一嘴

### 4. 速成教程

`时长或字数 + 精通/速通/保姆级/手把手 + 对象`

- 10 分钟搞懂：为什么你的 AI 记不住你
- **兑现**：按顺序真能跟着做完；写了「避坑/提示词」就必须有独立段落

### 5. 社会证明

`Star / 下载 / 大厂 / 热榜 + 对象 + 它干成了什么`

- **兑现**：数字公开可查
- 🚫 **本项目默认不用**：没查到公开数据就不许写

### 6. 对比站队

`A 和 B 到底选哪个` / `实测 A 和 B` / `彻底抛弃了 X`

- 提示词和技能到底差在哪？同一个任务我试了两遍
- **兑现**：同一任务、可对比的维度、明确站队（不分场景和稀泥）

### 7. 情绪短句

短、口语、带情绪（慌 / 杀疯了 / 拉完了 / 有福了 / 卷到）

- 跟 AI 说了一百遍，它还是不懂我
- **兑现**：后面必须有干货
- **默认只出 1 条**

### 8. 概念降维（小红书新增）

把专业词翻成一句人话

- 提示词是一次性的任务，技能是能存下来的做法
- **兑现**：翻完之后读者能拿去跟别人复述

## 三、写法细则

- **工具名尽量出现在前 16 字**：信息流截断后仍能看懂在讲谁
- **数字要具体**：7、10、50、209 页、3.5 万 Star —— 禁止「多个」「一系列」
- **第一人称优先**：「我用 / 我让 / 我把 / 亲测」通常优于「如何如何」
- **身份词是点击开关**：缺身份时可以补，但**只补一个**，且正文要按该身份写场景
- **口语 > 书面**：档位、杀疯了、有福了、卷到 —— 但**禁止空喊**震惊、重磅、炸裂、必看
- **附赠括号是履约承诺**：`（附提示词）` `建议收藏` —— 标题写了，正文必须有对应物
- **不要为了具体而编造**：具体化必须来自真实或**普遍成立**的事实。
  ❌「上周你跟 AI 说过的那句话」（为什么是上周？编的）
  ✅「同一件事，你跟 AI 说过多少遍了？」（普遍成立）

---

## 四、缺元素时怎么补

从内容里抽：对象、身份、数字、结果、冲突、代价、附赠物。

| 缺什么 | 可以补 | 不可以补 |
|---|---|---|
| 身份 | 按内容推断**一个**，并标注需兑现 | 同时堆三个身份 |
| 数字 | 用正文里真实可数的条数；没有就改用不依赖数字的公式 | 编造 Star、下载量、实验样本量 |
| 结果 | 用已有的结论收紧 | 发明没做过的「反超 8.7 分」 |
| 附赠 | 仅当确实会提供教程 / 提示词 / 清单 | 空挂「附完整教程」 |

## 五、8 个选题模板

高转化选题同时满足三件事：**具体对象 + 可感知结果 + 读者身份或情绪**。
只有热点没有用法，或只有教程没有钩子，都偏弱。

| # | 模板 | 何时用 | 槽位 | 正文要兑现 |
|---|---|---|---|---|
| 1 | 必装清单 | 有一组可执行物 | 身份 + N 个 + 对象 | 真有 N 条，每条有场景 |
| 2 | 亲测复盘 | 做过够夸张的实验或批量分析 | 我用 X 做了 Y + 得到 Z | 过程可复述，数字真实 |
| 3 | 从 0 到 1 教程 | 读者不会用、刚听说 | 门槛 + 手把手 + 对象 | 跟着做完；避坑要有独立段落 |
| 4 | 热点产品落地 | 新功能发布 24–72h 内 | 产品名（前 16 字）+ 玩法数 + 附赠 | 至少一种可复现玩法，禁复述发布会 |
| 5 | 对比抉择 | 两个概念/工具被混用 | A 和 B 到底差在哪 | 同一任务 + 明确站队 |
| 6 | 开源神器安利 | 有硬社会证明 | Star/下载 + 它解决的一件具体事 | 数字可查 + 一个真实用例 |
| 7 | 身份场景化 | 工具不新，但接到具体岗位就成新选题 | 身份 + 用 X 做 Y | 场景细节要像那个身份真会遇到的 |
| 8 | 反常识 / 情绪钩 | 能挑战读者正在做的事 | 你以为 A，其实 B | 反转要给机制，不能只骂一嘴 |

**映射提示**（内容像什么 → 优先哪个模板）：

| 内容像什么 | 优先模板 |
|---|---|
| 推荐、必装、合集、N 个 | 1 必装清单 |
| 我测了、踩坑、复盘 | 2 亲测复盘 |
| 不会用、教程、从 0 到 1、接入 | 3 从 0 到 1 教程 |
| 刚发布、终于来了 | 4 热点产品落地 |
| A 还是 B、对比、容易被混用 | 5 对比抉择 |
| GitHub、Star、开源、替代 XX | 6 开源神器安利 |
| 电商 / 体制内 / 上班族 / 一人公司 | 7 身份场景化 |
| 吐槽、误区、反直觉、坏习惯 | 8 反常识 / 情绪钩 |

## 六、封面设计规则（吸睛的关键）

封面必须同时做到三件事，缺一个就不合格：

1. **3 秒内看懂讲什么** —— 主标题就是结论或冲突，**不能是悬念句**
2. **有视觉证据** —— 对比卡 / 数字 / 图解，不能只有字
3. **有理由点开** —— 钩子标签（「90% 的人卡在这一步」）+ 附赠承诺（「附清单」）

**封面结构（自上而下）**

```
[钩子标签]      橙底白字胶囊，8–12 字，给紧迫感或人群
[主标题]        得意黑，96–110px，2 行，第 1 行最有信息量
[副标题]        40–46px，一句给解法
[视觉证据]      对比卡 / 图解 / 数字条（占版面 30–40%）
[角标]          2 个胶囊：价值承诺 + 内容形式
```

**视频封面同用这一套。** 视频封面**必须是静止可读的**，不能依赖动效表达信息。

## 八、失败信号（出现即重写）

- `XX 发布了` / `盘点 XX` / `关于 XX 的思考`
- 通稿体、正确废话（「AI 正在改变我们的工作方式」）
- 震惊、重磅、炸裂、必看
- 「多个」「一系列」「干货满满」
- **只有代价没有结果**（「同一个要求你说了 100 遍」—— 然后呢？读者不知道你想说什么）
- 备选之间只改两个字
- 标题写了附教程 / 提示词，兑现点却是空的
- 编造 Star、下载量、实验样本、对比分数
- 为了具体而编造具体时间 / 数量（「上周」「三天前」）
- 封面主标题是悬念句
- 视频口播钩子和封面主标题是同一句话

## 九、自检清单

出稿前逐条过：

- [ ] 封面主标题 ≤ 16 字，第 1 行有信息量
- [ ] 标题里有具体数字或明确冲突
- [ ] 有身份词，或至少谁都能看懂
- [ ] 封面有视觉证据，不是纯文字
- [ ] **1 条主选 + 3 条备选，公式不重复**
- [ ] 主选标题的承诺能在正文兑现
- [ ] 没有禁用词、没有编造数字、没有为了具体而编造
- [ ] 正文首行标题 ≤ 20 字
- [ ] （视频）口播钩子和封面主标题是两条不同的话
